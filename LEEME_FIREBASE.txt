2. PASO OBLIGATORIO EN FIREBASE CONSOLE PARA QUE SE GUARDEN LOS REGISTROS:
   Entra a: https://console.firebase.google.com/project/project-2998039825269712276

   A) REGLAS PARA CLOUD FIRESTORE (Recomendado):
      1. En el menú izquierdo ve a "Compilación (Build)" -> "Firestore Database".
      2. Si aún no está creada la base de datos, haz clic en "Crear base de datos" (Create database).
      3. Ve a la pestaña "Reglas" (Rules), pega este bloque y haz clic en "Publicar" (Publish):

rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /{document=**} {
      allow read, write: if true;
    }
  }
}

   B) REGLAS PARA REALTIME DATABASE (Opcional / Respaldo):
      Si también activas "Realtime Database", entra a su pestaña "Reglas" (Rules),
      pega este bloque y haz clic en "Publicar" (Publish):

{
  "rules": {
    ".read": true,
    ".write": true
  }
}
